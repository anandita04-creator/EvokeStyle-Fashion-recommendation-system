# EvokeStyle-Fashion-recommendation-system
Tech Stack: Python, CLIP, Embedding Models, Image Similarity Search

• Designed and developed a body shape–aware fashion recommendation system that generates personalized outfit suggestions using multimodal embeddings.

• Implemented body shape classification based on user-provided measurements and mapped shapes (e.g., pear, hourglass, rectangle) to style rules such as wrap, A-line, and belted silhouettes.

• Leveraged CLIP-based image embeddings to compute semantic similarity between user preferences and fashion catalog images for intelligent style ranking.

• Integrated attribute-based filtering (color, sleeve type, clothing category) prior to embedding similarity search to improve recommendation precision.

• Built and deployed an interactive demo using Hugging Face Spaces for real-time outfit recommendations.

🔗 Live Demo: https://huggingface.co/spaces/Anandita-04/Evokestyle
